> 在线体验：<https://你的用户名.github.io/仓库名/>
> （首次部署后请把上面链接替换成你的真实地址）

## 这是什么

亚马逊后台的数据往往不够直观：类目排名要怎么冲？冲多久能超过第一名？广告 ROI 划不划算？利润到底剩多少？

这个仓库把这些高频运营决策，做成**一个个独立的网页计算器**：输入几个数字，直接得到答案。手机端也能正常打开，随时可以用来做决策。

当前收录工具：

| 工具 | 说明 | 状态 |
| --- | --- | --- |
| BSR 反超测算器 Pro | 多目标档位 Top 1/3/5/10 × 三种冲刺节奏（匀速 / 递增 / 促销爆量）对比。用幂律门槛 + 加权滚动窗口模型，算出反超所需日均单量、天数、累计投入与预计达成日；另含「同比大盘诊断」（λ / η） | 可用 |
| 利润与广告承受力计算器 | 算清单件毛利与毛利率，推出盈亏平衡 CPA / ACOS 与「目标净利率下的允许 CPA」，再据 BSR 工具给出的门槛 U* 反推卡位所需日均补单、广告预算与回本天数 | 可用 |

**两个工具如何配合**

```
BSR 测算器 Pro  →  每天要卖多少单（U*、天数、节奏）
        ↓ 把 U* 填进
利润计算器      →  这么投每天花多少钱、允许 CPA 是多少、多少天回本
```

决策闭环：先用 BSR 工具确认「能不能冲得上」，再用利润计算器确认「值不值得冲」。

配套方法论文档《亚马逊 BSR 运营作战方案》：指标口径与定义、输入字段清单及缺失替代处理、敏感性分析、日常数据采集频率与字段、排名波动归因方法、卡位与广告/促销节奏配合、季节性与大盘异常修正、落地 Checklist。

后续会根据实际运营中的真实痛点持续补充新工具。

## 在线使用

直接用上方「在线体验」链接即可，不需要本地部署。

如果你把这个仓库 Fork 到自己的账号，推荐用 **GitHub Pages** 或 **Netlify** 部署，两种方式都免费、过程只要几分钟。

## 本地运行

所有工具都是**单个 HTML 文件、零外部依赖**，本地使用非常简单：

- 直接双击 `index.html`，浏览器打开即可使用。

如果想用本地服务器预览（可选）：

```bash
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

## 部署到你自己的站点

**方式一：Netlify（最快，30 秒）**

1. 打开 <https://app.netlify.com/drop>
2. 把包含 `index.html` 的文件夹整个拖进去
3. 自动部署完成，得到 `https://xxxxxx.netlify.app` 网址

**方式二：GitHub Pages（稳定、长期）**

1. 仓库 Settings → Pages
2. Source 选 `main` 分支，路径 `/root`
3. 保存后 1–2 分钟生成 `https://用户名.github.io/仓库名/`

**方式三：放进你已有的网站**

用 iframe 嵌入即可，样式完全隔离、不会和你原有页面冲突：

```html
<iframe
  src="https://你的域名.com/tools/"
  style="width:100%;height:520px;border:none;"
  title="亚马逊 BSR 反超测算器">
</iframe>
```

## 免责声明

本仓库工具的计算结果基于**公开经验模型**——BSR 测算先用「类目排名-销量幂律 `U(r)=K·r^(−α)`」推算目标排名门槛，再叠加「7 天加权滚动窗口」仿真达成天数。亚马逊的真实排名算法并未对外公开，因此数值结果仅用于**测算方向和辅助决策**，不构成任何运营承诺或收益保证。

实际排名与出单还会受到转化率、review、价格、广告投放、竞争对手动态等多重因素影响，请结合自身实际情况判断。
