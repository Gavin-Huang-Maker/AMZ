## 这是什么

亚马逊后台的数据往往不够直观：类目排名要怎么冲？冲多久能超过第一名？广告 ROI 划不划算？利润到底剩多少？

这个仓库把这些高频运营决策，做成**一个个独立的网页计算器**：输入几个数字，直接得到答案。手机端也能正常打开，随时可以用来做决策。

当前收录 **21 个工具**，分为 6 大类。

**推荐决策闭环**

```
BSR 测算器 Pro  →  每天要卖多少单（U*、天数、节奏）
        ↓ 把 U* 填进
利润计算器      →  这么投每天花多少钱、允许 CPA 是多少、多少天回本
        ↓ 执行前
断货测算 + 红线预警  →  确认兜得住
```

决策闭环：先用 BSR 工具确认「能不能冲得上」，再用利润计算器确认「值不值得冲」，最后用风控类工具确认「出了事兜不兜得住」。

## 在线使用

直接用上方「在线体验」链接即可，不需要本地部署。

如果你把这个仓库 Fork 到自己的账号，推荐用 **GitHub Pages** 或 **Netlify** 部署，两种方式都免费、过程只要几分钟。

## 本地运行

所有工具都是**单个 HTML 文件、零外部依赖**，本地使用非常简单：

- 直接双击 `index.html`，浏览器打开即可使用。

如果想用本地服务器预览（可选）：

```bash
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

## 部署到你自己的站点

**方式一：Netlify（最快，30 秒）**

1. 打开 <https://app.netlify.com/drop>
2. 把包含 `index.html` 的文件夹整个拖进去
3. 自动部署完成，得到 `https://xxxxxx.netlify.app` 网址

**方式二：GitHub Pages（稳定、长期）**

1. 仓库 Settings → Pages
2. Source 选 `main` 分支，路径 `/root`
3. 保存后 1–2 分钟生成 `https://用户名.github.io/仓库名/`

**方式三：放进你已有的网站**

用 iframe 嵌入即可，样式完全隔离、不会和你原有页面冲突：

```html
<iframe
  src="https://你的域名.com/tools/"
  style="width:100%;height:520px;border:none;"
  title="亚马逊 BSR 反超测算器">
</iframe>
```
