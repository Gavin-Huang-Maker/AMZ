✍️ 加热品类表达矩阵

把「需求词雷达」抓到的人群 × 痛点 × 部位直接变成能贴进后台的句子： 标题、五点、A+ 模块、QA、视频钩子一次生成。每一句都过疗效宣称红线扫描 —— 美英加通用规则 + 德国站 HWG 特殊规则，红色句子绝不能上线。

1. 选站点与切入点

疗效宣称红线（为什么有的句子标红）

红线词（美国 / 英国 / 加拿大）treat / cure / heal / medical device / FDA approved / therapy device —— 涉嫌把保暖产品说成医疗器械，会被下架或要求提供证明
慎用词arthritis / sciatica / neuropathy 直接点名疾病、"pain relief for X 病"句式 —— 写"soothing warmth for stiff shoulders"这类感受句更安全
德国站特有（HWG 药品广告法）heilt / Heilung / lindert Krankheiten / wirkt bei ... —— 德国对疗效宣称的执法比美国严格得多，只用"wohltuende Wärme"（舒缓的温暖）这类表述
