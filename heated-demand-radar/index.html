🔥 加热需求词雷达

需求先出现在讨论和搜索里，才轮到亚马逊。这个工具一边去 Reddit 真实讨论和搜索联想词抓原话， 一边让你粘贴 TikTok / IG / YouTube 的标题和评论，然后自动给每条内容打上场景 / 人群 / 部位 / 痛点 / 产品诉求标签， 四个站点各自跑各自的本地语言，最后给你一份能直接投放的词包。

1. 取数据

点击后自动尝试三个通道；任一通道失败会自动降级到内置词库，页面永远有东西可看
配合下面的书签小工具用：在 TikTok / IG 页面点一下书签，回来点这里即可

尚未取数 —— 直接点上面按钮，或粘贴内容后点「分析」即可。

2. 把 TikTok / Instagram 的内容拿来（三步，一分钟内）

这两个平台的登录墙 + 反爬 + 跨域限制，任何网页都抓不到 —— 但跑在你自己浏览器里的脚本可以，因为你本来就登录着。这就是下面这个书签的原理。

1
把书签拖到书签栏
📋 抓取本页文案（拖我到书签栏）
用鼠标把这个按钮拖到浏览器的书签栏（Ctrl+Shift+B 可显示书签栏）。Chrome / Edge 都支持。
2
在平台页面点它
打开 TikTok 搜索页或话题页、IG 话题页、YouTube 搜索页、Reddit 搜索页 —— 先往下滚两三屏让内容加载出来，再点书签栏里那个书签，会提示「已复制 N 条」。
3
回来点「从剪贴板导入」
就是上面粘贴区旁边的那个按钮，点完词榜立刻重算，标签、词频、词包全部按你抓来的真内容重出。
只抓到几条怎么办：这些页面是滚动加载的，滚得越多抓得越多。滚完再点一次书签即可，代码是幂等的，重复内容会自动去重。
什么都没抓到：页面结构变了（平台会改版）时也偶尔失效 —— 这时直接手动框选页面上的文案复制，粘贴到上面的框里，效果完全一样。

三条通道分别负责什么

Reddit 讨论症状与人群的原生语言。这里写的句式可以直接搬进五点第一条，比你自己想更贴近真实表达
搜索联想词真实的人在搜索框里敲了什么，代表购买意图。用来做 SP 精准词和标题词根
手动粘贴TikTok / IG / YouTube 的内容。这三个平台禁止网页直连（登录墙 + 反爬 + 跨域），所以由你复制过来
每天自动更新网页只负责看图；每天定时刷新交给 WorkBuddy 自动化，它会取数后把当天新增词推到企业微信

词频是相对值不是绝对值：语料越大排序越稳。每天跑一次，看「今日新增」那一列才有意义 —— 新冒出来的词就是需求变化的信号。
